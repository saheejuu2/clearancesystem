================================================================================
                          KEY FEATURES
================================================================================

✅ REAL-TIME UPDATES
   - Patient admissions appear instantly
   - Clearances update in real-time
   - Discharges reflect immediately
   - No page refresh needed

✅ AUTOMATIC FALLBACK
   - If WebSocket unavailable, uses polling (30 seconds)
   - Transparent to users
   - Automatic reconnection attempts

✅ EFFICIENT SUBSCRIPTIONS
   - Clients only receive updates for their role and date
   - Reduces bandwidth usage
   - Scales better than polling

✅ CONNECTION MANAGEMENT
   - Automatic reconnection with exponential backoff
   - Keep-alive pings every 30 seconds
   - Graceful disconnection handling

✅ ERROR HANDLING
   - Connection failures logged to console
   - Automatic fallback to polling
   - User-friendly error messages

                          QUICK START
================================================================================

1. INSTALL DEPENDENCIES
   $ npm install

2. START WEBSOCKET SERVER
   $ npm run ws-server
   
   Expected output:
   WebSocket server listening on port 8080
   Waiting for connections...

3. TEST CONNECTION
   $ npm run test-ws
   
   Expected output:
   ✅ Passed: 4
   ❌ Failed: 0

4. START APPLICATION
   Terminal 1: cd api && php -S localhost:8000
   Terminal 2: cd frontend && npm run dev

5. VERIFY IN BROWSER
   - Open Developer Console (F12)
   - Look for "WebSocket connected" message
   - Perform actions and verify instant updates

================================================================================
                        TROUBLESHOOTING
================================================================================

ISSUE: WebSocket connection fails
SOLUTION: 
  - Verify npm run ws-server is running
  - Check port 8080 is not blocked
  - Check browser console for errors

ISSUE: Updates not appearing
SOLUTION:
  - Check WebSocket server is running
  - Verify client is subscribed (check console logs)
  - Check network tab for WebSocket messages

ISSUE: Server crashes
SOLUTION:
  - Restart with: npm run ws-server
  - Check for errors in server logs
  - Verify Node.js version is 14+

See QUICKSTART.md for more troubleshooting.
